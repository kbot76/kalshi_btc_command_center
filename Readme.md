# Kalshi BTC Command Center

An AI-powered Bitcoin market analysis and trading research system designed for Kalshi 15-minute BTC markets.

## Project Goals

- Analyze Bitcoin market direction.
- Identify potential bullish and bearish reversals.
- Calculate estimated UP/DOWN probabilities.
- Monitor Binance live market data.
- Analyze order book imbalance and trading volume.
- Detect momentum shifts and breakout opportunities.
- Compare multiple timeframes.

## Market Analysis

Primary timeframe:
- 15-minute market direction.

Confirmation timeframes:
- 5-minute momentum.
- 1-minute entry signals.

## Key Features

- Live Binance BTCUSDT data.
- Reversal probability analysis.
- Market momentum detection.
- Order book analysis.
- Cross-exchange price comparisons.
- Risk management.
- Trade signal tracking.
- Performance statistics.

## Trading Rules

- Avoid low-confidence trades.
- Require measurable trading edge.
- Monitor consecutive losses.
- Use stop-loss protection.
- Test strategies before live deployment.
